# Glossary

## Git

**Working file**: the real file on disk in the current checkout. It is the only version of a file that you edit.

**Revision file**: the read-only content of a file as it is after a given commit. Opening one never changes the working tree, the index, or the current branch.
_Avoid_: checked-out file (checkout changes the working tree)

**Revision diff**: a side-by-side view with a revision file on the left and its working file on the right.
